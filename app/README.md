# Abonelik Takip Android Uygulaması

Flutter ile geliştirilen Android-first, local-first düzenli ödeme takip uygulaması.

İlk dikey dilim aylık düzenli ödeme ekleme, yaklaşan ödeme kartı, yerel bildirim planlama, vadesi gelen occurrence üretimi, ödendi/atlandı onayı ve para birimi bazlı aylık özeti kapsar. Veritabanı SQLite3MultipleCiphers ile şifrelenir; anahtar Android Keystore destekli güvenli depoda tutulur.

Kurulum ve doğrulama komutları için [`../docs/development/setup.md`](../docs/development/setup.md) belgesine bakın.
