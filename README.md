# Düzenli Ödeme Takibi

Android-first, local-first Flutter uygulaması. Çekirdek kullanım hesap veya internet gerektirmez.

## Mevcut aşama

Aşama 1: Flutter/Android altyapısı ve ilk çalışan dikey dilim.

## Kapsam sınırı

Bu aşamada Supabase, hesap, bulut yedekleme, iOS, canlı kur dönüşümü, otomatik fiyat takibi ve IAP bulunmaz.

Kurulum ve doğrulama komutları [docs/development/setup.md](docs/development/setup.md) içinde tutulur.
